# 생태건강돌봄연구소 웹사이트

생태건강돌봄연구소의 공개 웹사이트입니다. 건강, 질병, 건강돌봄, 보건의료를 생태적 관점으로 바라보고 건강 관련 제도정책과 사회문화의 생태적 전환을 모색하는 연구소 소개, 세미나, 연구 활동, 뉴스레터 정보를 담습니다.

## 운영 방식

- 정적 HTML/CSS 사이트입니다.
- Cloudflare Pages에서 빌드 명령 없이 배포할 수 있습니다.
- 운영진은 GitHub에서 HTML 파일의 문구와 링크를 수정하면 됩니다.

## Cloudflare Pages 설정

- Framework preset: `None`
- Build command: 비워둠
- Build output directory: `/`

## 주요 파일

- `index.html`: 첫 화면
- `about.html`: 연구소 소개
- `people.html`: 운영진
- `research.html`: 연구 활동
- `events.html`: 세미나와 행사
- `newsletter.html`: 뉴스레터
- `contact.html`: 연락처
- `styles.css`: 전체 디자인
- `assets/`: 이미지 자산
